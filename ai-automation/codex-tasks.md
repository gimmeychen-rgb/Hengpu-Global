# Codex Task System - Hengpu Global

## Purpose
This file defines executable AI tasks for automation via Codex or AI agents.

---

## 1. Supplier Data Structuring Task

Task:
- Collect supplier data
- Normalize format
- Categorize by industry and reliability

Output:
- Structured supplier database
- Tier classification

---

## 2. Pricing Table Generator

Task:
- Generate pricing models based on cost + risk + margin
- Adjust for different regions and client types

Output:
- Standardized pricing table
- Profit margin mapping

---

## 3. Client Analysis Automation

Task:
- Evaluate client information
- Assign trust level
- Suggest cooperation strategy

Output:
- Client classification report
- Risk score

---

## 4. Market Research Automation

Task:
- Analyze target country or industry
- Identify opportunities and risks

Output:
- Market entry report
- Strategic recommendation

---

## 5. Document Generator

Task:
- Generate business documents automatically
- Proposals, reports, summaries

Output:
- Structured business documents

---

## Core Rule

All tasks must be:
- Executable
- Structured
- Repeatable
- Business-oriented
