# AI Workflows - Hengpu Global

## Purpose
This file defines how AI tasks, business data, and execution systems are connected in Hengpu Global.

---

## 1. Supply Chain Workflow

Input:
- Supplier data
- Pricing structure
- Client request

Process:
- Analyze supplier options
- Match pricing model
- Evaluate client type

Output:
- Suggested supplier
- Recommended price
- Risk level

---

## 2. Pricing Workflow

Input:
- Cost data
- Region
- Client category

Process:
- Apply pricing model rules
- Adjust margin based on risk
- Generate final quotation

Output:
- Structured quotation
- Profit margin breakdown

---

## 3. Client Handling Workflow

Input:
- Client profile
- Inquiry details

Process:
- Classify client tier
- Assess trust level
- Select cooperation strategy

Output:
- Client classification
- Suggested action plan

---

## 4. AI Task Flow

Input:
- Business question or task

Process:
- Use prompts system for analysis
- Execute via Codex task system

Output:
- Structured business result

---

## Core Principle

All workflows must be:
- Repeatable
- Structured
- Actionable
- Automatable
