# Automation Input System

## Purpose
This file defines how external requests enter the Hengpu system.

---

## Input Sources

### 1. Client Requests
- Product inquiry
- Pricing request
- Cooperation proposal

### 2. Supplier Data
- Product list
- Pricing updates
- Capacity information

### 3. Internal Tasks
- Market research
- Strategy requests
- Analysis tasks

---

## Input Format

All inputs must include:
- Type (Client / Supplier / Internal)
- Description
- Required output

---

## Rule

No input is processed without classification.
