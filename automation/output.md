# Automation Output System - Hengpu Global

## Purpose
This system converts AI decisions into structured business deliverables.

---

## 1. Pricing Output Generator

Input:
- Cost data
- Client type
- Region risk

Output:
- Structured quotation
- Profit margin breakdown
- Final offer summary

---

## 2. Client Report Generator

Input:
- Client profile
- Interaction history
- Request type

Output:
- Client classification report
- Trust level assessment
- Recommended strategy

---

## 3. Supplier Recommendation Output

Input:
- Supplier database
- Product requirements
- Risk evaluation

Output:
- Ranked supplier list
- Recommended supplier
- Risk notes

---

## 4. Market Report Output

Input:
- Target country or industry
- Market data
- AI analysis

Output:
- Market overview
- Opportunity analysis
- Entry strategy

---

## 5. Core Rule

All outputs must be:
- Structured
- Ready for business use
- Clear and actionable
- Consistent in format
